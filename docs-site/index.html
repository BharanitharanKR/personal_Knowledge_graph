First launch: your OS will warn you

Sedge isn't code-signed — signing certificates cost money and this is a personal project. Your operating system can't tell "unsigned" from "unsafe", so it will object the first time. Here's how to get past it.

macOS

Drag Sedge to Applications, then run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/Sedge.app

Or right-click the app → Open → Open in the dialog.

Windows

SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway.

Linux

Make the AppImage executable (chmod +x Sedge-*.AppImage) and run it, or install the .deb.

Every release ships a SHA256SUMS.txt so you can verify what you downloaded.

What it is

A block-based editor for notes that link to each other — outlines, documents, daily notes, a searchable graph of everything you've written. It runs entirely on your machine, and your notes are plain files in a folder you choose.

Nothing to sign up for

There is no account system at all. Open it and start writing.

Your files, your disk

Notes live in a normal folder. Back them up however you already back things up.

Sync is optional and yours

Point it at your own S3 bucket, a WebDAV server, or a synced folder. No middleman.

Plugins and themes work

Reads the same public community index, so existing extensions keep working.
